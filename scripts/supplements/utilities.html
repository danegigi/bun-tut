A grab-bag of small, fast helpers on the Bun global that save you a dependency or a few lines.

Environment

Bun.env.API_KEY            // like process.env, populated from .env files
Bun.env.NODE_ENV ?? "development"

Timing

await Bun.sleep(1000);      // async pause, 1s (also accepts a Date)
Bun.sleepSync(50);          // blocking pause — use sparingly
Bun.nanoseconds();          // ns since process start (high-res timing)

const start = Bun.nanoseconds();
doWork();
console.log((Bun.nanoseconds() - start) / 1e6, "ms");

Locating executables

Bun.which("node");         // "/usr/local/bin/node" or null
Bun.which("git", { PATH: "/usr/bin" });

HTML escaping

Bun.escapeHTML('<script>alert("x")</script>');
// "&lt;script&gt;alert(&quot;x&quot;)&lt;/script&gt;"

Deep equality

Bun.deepEquals({ a: [1, 2] }, { a: [1, 2] });        // true
Bun.deepEquals({ a: 1 }, { a: 1, b: undefined });    // false
Bun.deepEquals({ a: 1 }, { a: 1, b: undefined }, true); // strict: also false

Peeking at promises

Bun.peek reads a promise's value synchronously if it's already settled — useful in hot paths to skip an await tick.

const p = Promise.resolve(42);
Bun.peek(p);                 // 42 (already resolved)
Bun.peek.status(p);          // "fulfilled" | "rejected" | "pending"

const pending = fetch("...");
Bun.peek(pending);           // returns the promise itself (not settled yet)

Compression

const data = new TextEncoder().encode("compress me".repeat(100));

const gz = Bun.gzipSync(data);        // Uint8Array
const back = Bun.gunzipSync(gz);

Bun.deflateSync(data);   Bun.inflateSync(...);
Bun.zstdCompressSync(data);   // zstd

File helpers

await Bun.file("a.txt").exists();
Bun.pathToFileURL("/tmp/x.txt");    // file:// URL
Bun.fileURLToPath("file:///tmp/x.txt");

UUIDs & misc

crypto.randomUUID();       // standard v4 (Web Crypto — built in)
Bun.randomUUIDv7();        // time-ordered v7 — sortable, great for DB keys
Bun.randomUUIDv5("name", "dns");   // deterministic v5 from a namespace

// deep partial match (does b's shape appear in a?)
Bun.deepMatch({ a: 1, b: 2 }, { a: 1 });        // true

// ANSI helpers for terminal output
Bun.stripANSI("\x1b[31mred\x1b[0m");   // "red"
Bun.stringWidth("café");               // 4
Bun also ships larger built-in clients beyond these helpers: Bun.redis (a Redis client) and Bun.SQL (see Databases), plus Bun.Transpiler for programmatic TS→JS. They're documented in the reference index.

Real-life example: a micro-benchmark harness

Compare two implementations with high-resolution timing — the honest way to settle a "which is faster" argument, using Bun.nanoseconds().

function bench(name: string, fn: () => void, iterations = 100_000) {
  fn();                                   // warm up (JIT)
  const start = Bun.nanoseconds();
  for (let i = 0; i < iterations; i++) fn();
  const ms = (Bun.nanoseconds() - start) / 1e6;
  console.log(`${name.padEnd(20)} ${ms.toFixed(2)}ms  (${(ms / iterations * 1000).toFixed(3)}µs/op)`);
}

const data = { a: 1, b: [2, 3], c: { d: 4 } };
bench("JSON.parse/stringify", () => JSON.parse(JSON.stringify(data)));
bench("Bun.deepEquals", () => Bun.deepEquals(data, data));

Real-life example: retry with backoff

// Retry a flaky async op with exponential backoff + jitter, using Bun.sleep
async function withRetry<T>(fn: () => Promise<T>, tries = 5): Promise<T> {
  let lastErr: unknown;
  for (let attempt = 0; attempt < tries; attempt++) {
    try {
      return await fn();
    } catch (err) {
      lastErr = err;
      const delay = Math.min(1000 * 2 ** attempt, 15_000) + Math.random() * 250;
      await Bun.sleep(delay);
    }
  }
  throw lastErr;
}

const data = await withRetry(() => fetch("https://flaky.example.com/api").then((r) => {
  if (!r.ok) throw new Error(`HTTP ${r.status}`);
  return r.json();
}));
Bun.nanoseconds() is monotonic and unaffected by wall-clock changes, so it's the right timer for benchmarks and timeouts — Date.now() can jump backward on NTP sync. The jitter in the backoff matters at scale: without it, many clients that failed together retry in lockstep and stampede the recovering service.
