Bun has a built-in Jest-compatible test runner. No Jest, Vitest, or Mocha needed — just name files *.test.ts (or .spec.ts) and run bun test.

Your first test

// math.test.ts
import { test, expect, describe } from "bun:test";

test("adds numbers", () => {
  expect(2 + 2).toBe(4);
});

describe("strings", () => {
  test("uppercases", () => {
    expect("bun".toUpperCase()).toBe("BUN");
  });
});
bun test                # run all tests
bun test math           # only files matching "math"
bun test --watch        # re-run on change
bun test --coverage     # coverage report

Matchers

expect(value).toBe(4);                    // ===
expect(obj).toEqual({ a: 1 });            // deep equality
expect(arr).toContain("x");
expect(fn).toThrow("boom");
expect(str).toMatch(/regex/);
expect(value).toBeDefined();
expect(promise).resolves.toBe(42);        // async
await expect(promise).rejects.toThrow();
expect(n).toBeGreaterThan(3);
expect(x).toBeNull();

Lifecycle hooks

import { beforeAll, afterAll, beforeEach, afterEach } from "bun:test";

beforeAll(() => { /* once before all tests in the file */ });
afterAll(() => { /* once after all */ });
beforeEach(() => { /* before each test */ });
afterEach(() => { /* after each test */ });

Mocks & spies

import { mock, spyOn, test, expect } from "bun:test";

// a mock function
const fn = mock((x: number) => x * 2);
fn(21);
expect(fn).toHaveBeenCalledTimes(1);
expect(fn).toHaveBeenCalledWith(21);
expect(fn.mock.results[0].value).toBe(42);

// spy on an existing method
const obj = { greet: (n: string) => `hi ${n}` };
const spy = spyOn(obj, "greet");
obj.greet("Ada");
expect(spy).toHaveBeenCalledWith("Ada");

// module mock
mock.module("./config", () => ({ default: { env: "test" } }));

Snapshots

test("renders", () => {
  const output = render({ title: "Bun" });
  expect(output).toMatchSnapshot();     // writes __snapshots__ on first run
});
bun test --update-snapshots      # accept new snapshots

Skip, only, todo, and conditionals

test.skip("not yet", () => {});
test.only("focus on this", () => {});
test.todo("write me later");
test.each([[1, 1], [2, 4], [3, 9]])("square(%i) = %i", (n, sq) => {
  expect(n * n).toBe(sq);
});

Preloading setup

# bunfig.toml
[test]
preload = ["./test/setup.ts"]      # runs before the suite

Real-life example: integration test of an API route

Test a real handler against an isolated in-memory database, exercising the full request→response path — the pattern for testing a service without mocking your own code.

// orders.test.ts
import { test, expect, beforeEach, afterEach } from "bun:test";
import { Database } from "bun:sqlite";
import { makeApp } from "../src/app";        // (db) => Hono app

let db: Database;
let app: ReturnType<typeof makeApp>;

beforeEach(() => {
  db = new Database(":memory:");             // fresh DB per test — full isolation
  db.run("CREATE TABLE orders (id INTEGER PRIMARY KEY, total INTEGER)");
  app = makeApp(db);
});
afterEach(() => db.close());

test("POST /orders creates an order", async () => {
  const res = await app.request("/orders", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ total: 99 }),
  });
  expect(res.status).toBe(201);
  expect(await res.json()).toMatchObject({ id: 1, total: 99 });

  // Assert the side effect really happened
  const row = db.query("SELECT total FROM orders WHERE id = 1").get();
  expect(row).toEqual({ total: 99 });
});

test("GET /orders/:id returns 404 for missing", async () => {
  const res = await app.request("/orders/999");
  expect(res.status).toBe(404);
});
Two techniques that make integration tests fast and reliable: app.request(...) (Hono's built-in fetch harness) hits the real router with no network or open port, and a per-test :memory: SQLite DB gives full isolation with zero teardown cost. Reserve mock() for third-party boundaries (payment gateways, email) — not your own database.
