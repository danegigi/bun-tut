Bun ships fast, native networking: an HTTP server, WebSockets, raw TCP and UDP sockets, a standard fetch, and Web Workers for CPU-bound work.

Bun.serve — HTTP server

The modern API uses a routes object with path params and per-method handlers. req.params holds matched segments.

const server = Bun.serve({
  port: 3000,
  routes: {
    "/": () => new Response("Hello, Bun!"),

    "/users/:id": (req) => {
      return Response.json({ id: req.params.id });
    },

    "/api/echo": {
      POST: async (req) => Response.json(await req.json()),
    },
  },
  // fallback for unmatched routes
  fetch() {
    return new Response("Not found", { status: 404 });
  },
});

console.log(`Listening on ${server.url}`);   // http://localhost:3000

Static responses & streaming

Bun.serve({
  routes: {
    // serve a file straight from disk (uses sendfile under the hood)
    "/logo.png": () => new Response(Bun.file("./assets/logo.png")),

    // stream a response
    "/stream": () => new Response(
      new ReadableStream({
        start(c) {
          c.enqueue("chunk 1\n");
          c.enqueue("chunk 2\n");
          c.close();
        },
      }),
      { headers: { "Content-Type": "text/plain" } },
    ),
  },
});

WebSockets

Return undefined from fetch after server.upgrade(req) to hand the connection to the websocket handlers.

Bun.serve({
  port: 3001,
  fetch(req, server) {
    if (server.upgrade(req)) return;      // upgraded — no Response needed
    return new Response("Use a WebSocket client");
  },
  websocket: {
    open(ws) { ws.subscribe("room"); ws.send("welcome"); },
    message(ws, msg) { ws.publish("room", `broadcast: ${msg}`); },
    close(ws) { ws.unsubscribe("room"); },
  },
});

subscribe/publish is Bun's built-in pub/sub — great for chat and live updates without extra libraries.

TCP sockets

// Server
Bun.listen({
  hostname: "localhost",
  port: 8080,
  socket: {
    open(socket) { socket.write("hi\n"); },
    data(socket, data) { socket.write(data); },   // echo
    close() { console.log("client gone"); },
  },
});

// Client
const client = await Bun.connect({
  hostname: "localhost",
  port: 8080,
  socket: {
    data(socket, data) { console.log("got", data.toString()); },
  },
});

UDP sockets

const udp = await Bun.udpSocket({
  socket: {
    data(socket, buf, port, addr) {
      console.log(`from ${addr}:${port}`, buf.toString());
    },
  },
});
udp.send("ping", 41234, "127.0.0.1");

fetch

The standard Web fetch — plus Bun extensions like the s3:// protocol and unix sockets.

const res = await fetch("https://api.github.com/repos/oven-sh/bun");
const repo = await res.json();
console.log(repo.stargazers_count);

// POST JSON
await fetch("https://httpbin.org/post", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ hello: "world" }),
});

Workers — offload CPU work

Use a Worker to keep the main thread responsive during heavy computation.

// worker.ts
self.onmessage = (e) => {
  const n = e.data;
  let sum = 0;
  for (let i = 0; i < n; i++) sum += i;
  postMessage(sum);
};
// main.ts
const worker = new Worker(new URL("./worker.ts", import.meta.url).href);
worker.postMessage(1_000_000_000);
worker.onmessage = (e) => {
  console.log("sum =", e.data);
  worker.terminate();
};
