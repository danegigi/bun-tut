Bun's file API is built on the Web Blob interface. Bun.file(path) returns a lazy BunFile — nothing is read until you call a method — and Bun.write() writes almost anything to almost anywhere.

Reading files

const file = Bun.file("./data.json");   // lazy — no read yet

await file.text();          // string
await file.json();          // parsed JSON
await file.bytes();         // Uint8Array
await file.arrayBuffer();   // ArrayBuffer
file.stream();              // ReadableStream

// metadata (no full read)
file.size;                  // bytes
file.type;                  // MIME type inferred from extension
await file.exists();        // boolean

Partial reads

const head = Bun.file("big.log").slice(0, 1024);   // first 1 KB
console.log(await head.text());

Writing files

Bun.write(dest, data) accepts a path, a BunFile, or an fd as the destination, and a string, bytes, Blob, Response, or another BunFile as the data.

await Bun.write("out.txt", "Hello!");
await Bun.write("copy.json", Bun.file("data.json"));      // copy a file
await Bun.write("page.html", await fetch("https://example.com")); // save a response
await Bun.write("bytes.bin", new Uint8Array([1, 2, 3]));

Incremental writing

For streaming or many small writes, use a writer:

const writer = Bun.file("log.txt").writer();
writer.write("line 1\n");
writer.write("line 2\n");
await writer.flush();     // push buffered data
await writer.end();       // close

Standard streams

const input = await Bun.stdin.text();       // read all stdin
await Bun.write(Bun.stdout, "to stdout\n");  // write to stdout
await Bun.write(Bun.stderr, "to stderr\n");

The s3:// protocol

The same Bun.file and fetch APIs transparently target S3-compatible storage — so dev-time local-file code works unchanged in production. (Full S3 details are in the Web Dev section.)

// Read an object from S3 with the same API as a local file
const remote = Bun.file("s3://my-bucket/report.json");
const data = await remote.json();

// fetch works too
const res = await fetch("s3://my-bucket/report.json");
Credentials come from S3_* / AWS_* environment variables (or an explicit s3: options object). See the Web Dev section for Bun.S3Client, presigned URLs, and multipart uploads.
