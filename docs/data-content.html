Bun treats structured data and content as first-class: config formats parse natively, images transform through a fast pipeline, archives pack and unpack, and Bun.WebView drives a headless browser for scraping — all built in.

JSON, YAML, TOML, JSON5

All four are first-class alongside JSON. You can import config files directly, and parse strings at runtime.

import { YAML, TOML, JSON5 } from "bun";

// Parse strings
const y = YAML.parse("name: Bun\nport: 3000");        // { name, port }
const t = TOML.parse(`title = "app"\n[db]\nport = 5432`);
const j = JSON5.parse(`{ unquoted: 1, trailing: 2, }`); // relaxed JSON

// Serialize
TOML.stringify({ title: "app", db: { port: 5432 } });
JSON5.stringify({ a: 1 });

// Multi-document YAML returns an array
YAML.parse("---\na: 1\n---\nb: 2");                    // [{a:1},{b:2}]

Import config files as modules (parsed at build/run time, hot-reloadable under --hot):

import config from "./config.yaml";        // default = whole doc
import { database, redis } from "./config.yaml";  // top-level keys = named exports

JSONC & JSONL

JSONC is JSON with comments and trailing commas (think tsconfig.json). JSONL is JSON Lines — one JSON value per line — common for logs and data streams.

import { JSONC, JSONL } from "bun";

// JSONC — comments + trailing commas allowed
const cfg = JSONC.parse(`{
  // app config
  "name": "my-app",
  "version": "1.0.0",   /* trailing comma ok */
}`);

// JSONL — array of values, one per line
const rows = JSONL.parse('{"a":1}\n{"b":2}\n');   // [{a:1},{b:2}]

// JSONL streaming — parseChunk never throws; returns { values, read, done, error }
let buffer = new Uint8Array(0);
for await (const chunk of stream) {
  buffer = Buffer.concat([buffer, chunk]);
  const { values, read, error } = JSONL.parseChunk(buffer);
  if (error) throw error;
  for (const v of values) handle(v);
  buffer = buffer.subarray(read);      // keep the unconsumed remainder
}
JSONL.parse returns whatever parsed successfully before an error (throwing only if nothing valid preceded it), and silently ignores an incomplete trailing line — which is exactly what you want when reading partial chunks.

Bun.XML

A conforming, non-validating XML 1.0 parser and serializer. The default compact shape keys elements by name, with @attr for attributes and #text for character data.

import { XML } from "bun";

// Parse (compact shape — good for data)
XML.parse(`<order id="A1"><item sku="x">Tea</item><item sku="y">Mug</item><paid/></order>`);
// {
//   order: {
//     "@id": "A1",
//     item: [ { "@sku": "x", "#text": "Tea" }, { "@sku": "y", "#text": "Mug" } ],
//     paid: "",
//   },
// }

// Document-order tree (keeps text position, comments, PIs)
XML.parse("<p>Hello <b>world</b>!</p>", { compact: false });

// Serialize (prepend the XML declaration yourself when writing a file)
const xml = XML.stringify({ order: { "@id": "A1", item: ["Tea", "Mug"], paid: null } }, null, 2);
// <order id="A1">...</order>
Security: Bun.XML never reads external DTDs or external entities (no XXE), and every value comes back as a string — nothing is coerced. Input must be well-formed or it throws a SyntaxError.

Bun.markdown — render markdown

Parse and render markdown to HTML, ANSI (for terminals), or React elements. GFM tables, strikethrough, and task lists are on by default.

// to HTML
const html = Bun.markdown.html("# Hello **world**\n\n- [x] done\n- [ ] todo");

// to ANSI for the terminal
const ansi = Bun.markdown.render("# Title\n\nSome **bold** text");
console.log(ansi);

// options: enable extras
Bun.markdown.html(src, { latexMath: true, wikiLinks: true, headings: { ids: true } });

Bun.Image — image pipeline

A chainable, Sharp-style pipeline (decode → transform → encode). Nothing runs until you await a terminal, and the work happens off the JS thread.

// Resize a photo and re-encode as WebP
await Bun.file("photo.jpg")
  .image()
  .resize(400, 400, { fit: "inside" })
  .webp({ quality: 80 })
  .write("thumb.webp");

// Read metadata without decoding pixels
const { width, height, format } = await new Bun.Image("photo.jpg").metadata();

// Transform chain
const bytes = await new Bun.Image(buffer)
  .rotate(90)
  .modulate({ brightness: 1.1, saturation: 0 })   // 0 saturation = greyscale
  .png()
  .bytes();

// Low-quality placeholder (tiny data: URL for blur-up loading)
const lqip = await Bun.file("hero.jpg").image().placeholder();

It composes with Bun.serve — a pipeline is a valid Response body:

Bun.serve({
  routes: {
    "/avatar/:id": async (req) => {
      if (!/^[a-z0-9]+$/.test(req.params.id)) return new Response(null, { status: 400 });
      const out = await Bun.file(`avatars/${req.params.id}.png`)
        .image().resize(128, 128).webp().blob();
      return new Response(out);
    },
  },
});
Validate any user-supplied path before passing it to Bun.Image(pathString) — a raw string is a file path (arbitrary-read primitive). For untrusted input, read into a Buffer first. HEIC/AVIF encode depend on OS codecs (macOS/Windows); on failure the terminal rejects with ERR_IMAGE_FORMAT_UNSUPPORTED — catch it and fall back to WebP.

Bun.Archive — tar / zip

Create and extract archives. Optional gzip compression.

// Create from an object of { path: contents }
const archive = new Bun.Archive(
  { "readme.md": "# Hello", "src/index.ts": "console.log(1)" },
  { compress: "gzip", level: 6 },
);
await Bun.Archive.write("bundle.tar.gz", archive);   // write to disk
const blob = await archive.blob();                    // or get a Blob

// Extract (returns number of entries written)
const src = new Bun.Archive(await Bun.file("bundle.tar.gz").bytes());
await src.extract("./out");

// Extract with a glob filter (same syntax as Bun.Glob)
await src.extract("./out", { glob: ["src/**", "!**/*.test.ts"] });

Bun.Glob — pattern matching

const glob = new Bun.Glob("**/*.ts");

// Scan the filesystem (async iterator)
for await (const path of glob.scan(".")) console.log(path);

// All matches at once
const files = await Array.fromAsync(glob.scan({ cwd: "./src" }));

// Sync
const sync = [...glob.scanSync("./src")];

// Match a string without touching disk
new Bun.Glob("*.{js,ts}").match("index.ts");   // true

Bun.color & Bun.inspect

// Convert colors between formats
Bun.color("#f472b6", "ansi");        // ANSI escape for terminals
Bun.color("red", "{rgb}");           // { r: 255, g: 0, b: 0 }
Bun.color("rgb(34,197,94)", "hex");  // "#22c55e"
Bun.color("#000", "number");         // 0

// Inspect any value like console.log formats it, but as a string
Bun.inspect({ a: 1, b: [2, 3] });    // "{\n  a: 1,\n  b: [ 2, 3 ],\n}"

Bun.WebView — headless browser & scraping

Bun.WebView is a headless browser built into the runtime — navigate pages, run JS inside them, click, and screenshot, with no Puppeteer/Playwright install (WKWebView on macOS, Chrome DevTools Protocol elsewhere).

await using view = new Bun.WebView();

await view.navigate("https://example.com");
const title = await view.evaluate("document.title");
await Bun.write("page.png", await view.screenshot());   // Blob by default

Scraping example — pull structured data out of a page:

await using view = new Bun.WebView({ width: 1280, height: 800 });

await view.navigate("https://news.ycombinator.com");

// Extract as a real JS value (round-trips via JSON)
const stories = await view.evaluate(`
  [...document.querySelectorAll('.titleline > a')]
    .slice(0, 10)
    .map(a => ({ title: a.textContent, url: a.href }))
`);

console.log(stories);   // [{ title, url }, ...]

// Interact: wait for an element to be actionable, then click
await view.click("a.morelink");
await view.screenshot({ format: "jpeg", quality: 80, encoding: "buffer" });

Input methods dispatch native events (isTrusted: true), click(selector) waits for the element to become actionable, and using/await using auto-closes the view. For persistence across runs, pass dataStore: { directory: "./profile" }.

Confirmed against the Bun 1.4.2 reference: constructor options (width, height, url, backend, console, dataStore), the click(selector, { timeout, button, clickCount, modifiers }) actionability wait, and the Modifier / VirtualKey sets are all as documented. On macOS the default "webkit" backend uses the system WebKit (nothing to install); on Linux/Windows pass backend: "chrome" to drive an installed Chrome/Chromium/Edge over the DevTools Protocol.

Real-life example: an image thumbnail pipeline

A build step that scans an image directory, generates responsive WebP thumbnails plus a blur placeholder for each, and writes a JSON manifest the frontend consumes — combining Bun.Glob, Bun.Image, and JSON.

import { Glob } from "bun";

const sizes = [320, 640, 1280];
const manifest: Record<string, unknown> = {};

for await (const src of new Glob("images/*.{jpg,png}").scan(".")) {
  const name = src.split("/").pop()!.replace(/\.\w+$/, "");
  const base = new Bun.Image(src);

  const { width, height } = await base.metadata();
  const lqip = await new Bun.Image(src).placeholder();     // tiny blur data: URL

  const variants: Record<number, string> = {};
  for (const w of sizes) {
    if (w > width) continue;                               // never upscale
    const out = `dist/img/${name}-${w}.webp`;
    await new Bun.Image(src)
      .resize(w, undefined, { withoutEnlargement: true })
      .webp({ quality: 80 })
      .write(out);
    variants[w] = out;
  }

  manifest[name] = { width, height, lqip, variants };
}

await Bun.write("dist/img/manifest.json", JSON.stringify(manifest, null, 2));
console.log(`processed ${Object.keys(manifest).length} images`);
Why this shape: placeholder() gives a ~400-byte blur you inline as the <img> background so the page has no layout shift while the real WebP loads; the manifest.json lets the frontend build a srcset from variants. The whole pipeline is one bun run — no ImageMagick, no sharp native build.

Real-life example: scrape a paginated list

// Collect items across N pages with Bun.WebView, respecting the site by pacing
await using view = new Bun.WebView();
const all: { title: string; url: string }[] = [];

for (let page = 1; page <= 5; page++) {
  await view.navigate(`https://example.com/products?page=${page}`);
  const items = await view.evaluate(`
    [...document.querySelectorAll('.product')].map(el => ({
      title: el.querySelector('h3')?.textContent?.trim(),
      url: el.querySelector('a')?.href,
    }))
  `);
  if (!items.length) break;              // reached the end
  all.push(...items);
  await Bun.sleep(500);                  // be polite between requests
}

await Bun.write("products.jsonl", all.map((x) => JSON.stringify(x)).join("\n"));
